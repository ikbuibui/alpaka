About alpaka

Abstraction Library for Parallel Kernel Acceleration. alpaka provides portable abstractions for parallel execution, memory, and algorithms. Its backends include serial execution, OpenMP, CUDA, HIP, and SYCL, so a shared kernel implementation can target different architectures.

The goal is performance portability, not automatic performance: choosing data layouts, work distribution, and tuning for the target hardware still matters.

What this explorer does—and does not do

The explorer runs alpaka’s actual C++ makeIdxMap implementation, compiled from this checkout to WebAssembly. JavaScript presents the resulting traces so you can inspect index ownership, traversal order, and nested mappings in one or two dimensions.

A tool for understanding

Change ranges, layouts, and worker groups; step through iterations; inspect assignments and C++ snippets; and share a configuration link.

Not a GPU simulator or benchmark

Worker contexts and device profiles are synthetic. The explorer does not execute GPU kernels, model hardware scheduling, or predict performance. Its results reflect this checkout, not every alpaka release.

The visualization runs locally in your browser after loading. It does not send configurations to an external compute service. For authoritative guidance, use alpaka’s official documentation.
